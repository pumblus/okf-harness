# Use one host-probe module for setup, doctor, and refresh

OKF Harness answers "is this executable on the host" once, from one host-probe module beside verification.ts, for universal setup, doctor, and refresh guidance. The four drifted executable-lookup and probe implementations (setup, doctor, refresh, agent-pack) converged into one module: a single executable-candidate policy (bare command name first, then PATHEXT variants and X_OK), probe orchestration with an injected runner, one Windows shell invocation strategy, one shadowing and global-version detection, and shared command-error readers. Consumers keep only presentation, and the unification fixes two behavior bugs in the same move: refresh guidance missed bare win32 names, and doctor's `.cmd` probes ran without a working directory. The change is net −300 lines.

One lookup policy answers the same question in every surface, so setup and doctor cannot disagree about a machine. A host executable is found or not found identically whether a person runs universal setup, asks doctor about the machine, or follows refresh guidance; the probe command, the shell strategy, and the shadowing check are the same code in all three. The module is invisible to agents and never appears in command output.

This record narrows what the Agent Plugin convergence records say about setup and doctor. When ADR 0050 and ADR 0051 say setup and doctor are unchanged or not modified, they mean their install surfaces, their installable host set, and the ADR 0044 and ADR 0045 mechanisms: the portable target renders, it never installs. Executable lookup itself is shared through this module, whose creation preceded that convergence, so a reader comparing the ADRs against the repository history finds no contradiction.

The cost accepted is that one lookup policy must serve three surfaces with different call shapes — synchronous probing with an injected runner, and an async boolean form for refresh guidance against an explicit runtime platform — and the shared policy is therefore exercised through both shapes rather than a single entry point.
