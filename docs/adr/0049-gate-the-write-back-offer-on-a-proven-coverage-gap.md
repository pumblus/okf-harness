# Gate the write-back offer on a proven coverage gap

OKF Harness should permit the agent to offer keeping an answer only when the evidence brief proves the synthesized wiki did not match the question. Harness proves the gap, the agent proposes, and the user's yes is the handover: one yes writes one ordinary concept page and its index link, and no answer writes nothing and persists nothing. The yes means only that the answer is worth keeping, never that the user certified it.

The gate is `NO_MATCHES` and nothing else. The permission arrives as one guidance string on the no-match branch of evidence planning, and its presence is the whole boolean: no structured field and no write-back command. The string appears on no other result, so an offer can never route around a consumption seal or duplicate a page the wiki already holds. A seal is not a gap: a fully sealed result keeps the gate shut, because declaring content unservable must actually withhold it. A truncated brief keeps it shut, because a budget artifact is not a coverage gap. A continuation read keeps it shut, because positive evidence that the wiki holds the content never reads as a gap. The gate measures the question's coverage, never the ingredients' provenance: an answer assembled from unanchored pages is not a gap.

The offer is ephemeral because the gate is idempotent and self-renewing. While nothing is written back, the wiki keeps not matching, so asking the same question reopens the offer. An ignored offer is not knowledge lost — it is knowledge that has not yet been asked for twice — and no queue, proposal entity, or persisted state is needed to keep it safe.

Two costs are accepted deliberately. The gate is lexical: it matches what search matched, so a mature wiki can miss an opportunity when it holds the content under words that do not match the question, and an agent that skips the offer or its disclosure is not caught by anything. If the gate later proves too strict, the repair path is to sharpen the coverage signal inside core, still byte-decidable, never to relax the gate into judgment.
