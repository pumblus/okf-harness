# Admit self-authored knowledge with zero anchors

OKF Harness should admit knowledge with no registered source behind it into the wiki. A page written back from a conversation is an ordinary concept page that happens to carry no citation. Zero anchors is a legitimate state and a silent one: no lint finding fires for it, `okfh check` says nothing about it, and no next step is offered. The removed missing-citations rule has no replacement signal, because the bytes cannot tell a deliberately unanchored claim from a forgotten citation.

Whether a page reaches a registered source is computed from the citation edges Harness already walks, by whichever consumer cares; it is never declared on the page. No frontmatter marker, no concept type, and no edge kind records an anchored-versus-unanchored status. Absence of an anchor is silent, but a declared anchor that does not land is not: a reference to an unregistered source still fires and still seals. In the evidence brief, the provenance pointer for an unanchored page is empty, and the emptiness is the signal. The answer workflow names when a load-bearing claim rests on pages whose provenance payload is empty, so the user always sees where the provenance trail ends; weight is never discounted, because disclosure protects retraceability.

Derived-from is ordinary prose plus a plain link. When a written-back answer drew on unanchored pages, the new page names them in its own prose; Harness parses, validates, and reports none of it.

`raw/` never receives written-back material. Write-back never captures the conversation as a source, so the raw layer stays purely the user's supplied material and the source manifest never gains a manufactured entry.

The currency seal keeps its subject. It proves that every promoted raw source has no unreconciled suspected revision, and it never widens to "the wiki is current." The machine predicate stays binary; the promoted-source count is reporting only, and a workspace that has promoted nothing is told there is nothing to reconcile rather than shown a vacuous seal.

An ingest that resolved a contradiction against a page reports the substance of the outcome: the page now cites a source it does not follow, and the divergence rests on a claim with no registered source behind it.

Two costs are accepted deliberately. A deliberately unanchored page is mechanically indistinguishable from a forgotten citation, and an agent that skips the disclosure or the lineage prose is not caught by anything: Harness can prove an obligation was delivered, never that it was honored. If the floor later proves too permissive, the repair path is to sharpen the coverage signal inside core, still byte-decidable, never to reintroduce judgment that bytes cannot carry.
